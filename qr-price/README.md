# AutoFlow QR-прайс

Демо-прайс: 15 услуг, категории, поиск, выбор работ, предварительный расчёт и запрос в WhatsApp.

Публикация: https://autoflow-price.vercel.app

Для отдельного Vercel-проекта используйте Root Directory: qr-price, Framework: Other. Сборка не требуется. Цены и WhatsApp изменяются в app.js. При смене домена обновите QR-код qr.svg и ссылку копирования в app.js.
