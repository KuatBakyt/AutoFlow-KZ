# AutoFlow Parts

Статический демонстрационный каталог: 12 товаров, категории, бренды, поиск по артикулу, наличие, карточки, корзина с количеством и localStorage, запрос в WhatsApp.

Данные и телефон редактируются в app.js. Все цены, остатки и артикулы демонстрационные. Применимость подтверждается отдельно. Изображения — схемы SVG, не фотографии брендов. Оплата и автоматический учёт склада не подключены.

Vercel: Framework Other; Root Directory parts-catalog; build/install не нужны. Для локального просмотра достаточно статического сервера.
