# AutoFlow KZ 1.0

Портфолио-концепт автосервиса для NovaWeb KZ. Не является действующей компанией.

## Запуск
Откройте `index.html` в Chrome или запустите локальный сервер: `python -m http.server 8000` из папки проекта и перейдите на http://localhost:8000.

## Возможности
Адаптивная вёрстка, мобильное меню, каталог услуг, выбор услуги с подстановкой в форму, горизонтальная галерея, валидация формы, подготовка WhatsApp-сообщения при настройке номера.

## Подключение WhatsApp
В `js/main.js` укажите `WHATSAPP_NUMBER` в международном формате без `+`, например номер клиента после его получения. Пока значение пустое, заявки **не отправляются** и не сохраняются.

## Контент и ограничения
Фотографии вырезаны из предоставленного пользователем визуального макета. Качество отдельных миниатюр ограничено разрешением исходника. Для коммерческого запуска замените их на оригинальные лицензированные фотографии. Все цены демонстрационные. Адрес, номер, режим работы не заданы. Видеоплеер не реализован: элемент на первом экране ведёт к фотогалерее. Нет backend, CRM или реального бронирования.

## Размещение
Загрузите содержимое папки на статический хостинг (например, GitHub Pages, Netlify или Cloudflare Pages). Настройте реальные данные клиента до публикации коммерческой версии.
